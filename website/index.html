MONO.STT 导入、校对、导出与分享

拖进音视频，逐字稿就出来了

转录在本机完成，模型也由本机管理。批量导入自动排队，片段逐段显示，不用把素材上传到任何服务。

  • 内置 Whisper Large v3 Turbo 与 Whisper Large v3
  • Windows 可用 CPU 或 NVIDIA CUDA，macOS 使用 CPU
  • 队列支持取消、重试与重启后恢复
  • 每个文件可单独配置纠错词与热词

导出与飞书，交给下一步

单条记录可导出 TXT、Markdown 和 SRT；多条记录可批量打包成 ZIP，也能直接发布到飞书云文档。

  • 单条导出 TXT / Markdown / SRT
  • 批量导出支持搜索、分页与跨页勾选
  • TXT、SRT 或两种格式打包进一个 ZIP
  • 配置飞书自建应用后可创建、更新、删除关联文档

数据留在你自己的设备上

转录记录、回听音轨和模型都放在本机目录。只有下载模型、检查更新和主动发布到飞书时才需要网络。

  • Windows：安装目录下的 data/ 与 models/
  • macOS：~/Library/Application Support/MONO.STT/
  • 记录保存在 data/mono.db，音轨在 data/audio/
  • 删除记录会清理配套音频，导入原件保持原位
