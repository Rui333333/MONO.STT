使用文档

从安装、模型配置到校对、导出和飞书发布，按模块查阅即可。当前正式版为 0.1.7，支持 Windows x64 与 macOS 14+ Apple Silicon。

安装

到官网下载对应平台的安装包：Windows x64 为 MONO.STT_0.1.7_x64-setup.exe（约 139.5 MB），macOS Apple Silicon 为 MONO.STT_0.1.7_arm64.dmg（约 108.2 MB）。两个安装包都内置转录引擎。

安装步骤

  • Windows：双击 EXE 按提示安装，可自选目录；覆盖安装沿用注册表里记录的目录。
  • macOS：打开 DMG，把 MONO.STT 拖入「应用程序」。当前安装包尚未完成 Apple 公证，首次打开可能出现系统提示，可在 Finder 中右键选择「打开」，或到「系统设置 → 隐私与安全性」中允许。
  • 首次启动按引导下载模型，或选择已有的模型目录，然后用内置普通话音频试转录。

macOS 最低系统版本为 14；Windows 上可在「偏好设置 → 通用 → 检查更新」手动检查新版。

首次设置与模型

首次设置会检测本机环境，让你选择语音模型与运行设备，并做一次试转录验证。

语音模型

  • Whisper Large v3 Turbo：速度与精度均衡，适合中英文日常转录。
  • Whisper Large v3：完整规模，多语种与复杂口音识别率更高。
  • 可直接下载所需权重，或关联本机已有的模型目录；下载源可在设置中切换。

运行设备

  • CPU：纯处理器运行，不占显存，适合无独显环境；macOS 版本使用 CPU。
  • NVIDIA CUDA：Windows 上使用兼容的 GPU 加速推理，长音频处理更快，需要可用的 CUDA 运行库。

模型目录可以在「偏好设置」中修改，模型文件始终保存在本机。

导入与转录

导入音频或视频，即可在本机生成带时间戳的逐字稿。0.1.7 起「新建转录」直接进入导入页，应用内不再提供录音与麦克风选择。

  • 拖拽文件到窗口、使用文件选择器、导入文件夹或粘贴文件，支持批量导入。
  • 导入的文件自动进入转录队列，转录片段逐段显示，不必等长音频全部完成。
  • 队列中的任务可取消、重试；重启应用后会恢复上次中断的任务。
  • 每个音视频文件可单独配置纠错词和热词，用来修正专有名词。
  • 时间戳限制在实际音轨范围内，避免超出音频长度。

时间轴校对

转录结果可以回听、校对和修改，适合整理访谈、课程和会议记录。

  • 点击时间戳即可跳转到对应位置回听，可调整播放速度。
  • 开启滚动跟随，播放时逐字稿自动滚动；也可随时「回到当前朗读行」。
  • 直接编辑逐字稿中的文字并保存，修改会写回当前记录。
  • 音频文件缺失时，点击播放会给出提示，导入原件仍保留在原位置。

导出与批量打包

单条记录可导出 TXT、Markdown 和 SRT；多条记录可一次打包成 ZIP。

  • 批量导出支持按标题或音频文件名搜索、分页浏览与跨页勾选。
  • 可选 TXT、SRT 或两种格式一起导出，打包进同一个 ZIP，文件名默认按本地时间生成。
  • SRT 会带上时间轴，适合做字幕；TXT / Markdown 适合整理成文稿。

飞书云文档

配置飞书自建应用凭据后，可以把转录内容直接写入飞书云文档。

  • 在飞书开发者后台创建自建应用，获取 App ID 与 App Secret，并开通云文档相关权限。
  • 填写目标文件夹链接或 token（选填）；留空时写入应用云空间。
  • 选择写入格式后创建并写入文档；再次写入会更新同一篇文档的正文，可复制链接快速打开。
  • 删除云文档会把已关联文档移到回收站，本地转录记录仍可查看和重新发布。

只有你主动点击「发布到飞书」时才会向飞书发起请求。

数据与隐私

语音识别和回听都在本机运行。下载模型、检查更新或主动发布到飞书时才需要网络。

  • Windows：转录与设置在安装目录下的 data/，默认模型目录为安装目录下的 models/。
  • macOS：~/Library/Application Support/MONO.STT/data/ 与 ~/Library/Application Support/MONO.STT/models/。
  • 转录记录保存在 data/mono.db，回听音轨保存在 data/audio/；两个平台都可在偏好设置中改模型目录。
  • 删除转录记录会清理应用保存的配套音频，导入的原件保留在原位置。

卸载应用不会自动删除上述数据；换电脑时请先备份 data 与 models 目录。

软件更新

  • Windows：应用启动后自动检查更新，也可在「偏好设置 → 通用 → 检查更新」手动检查。新版确认后会下载并验证签名，再由安装程序完成升级；安装时应用会关闭，请等转录队列结束。
  • macOS：在线更新暂未启用，需要到 GitHub Releases 下载新 DMG 手动覆盖安装。
  • 0.1.3 的用户需要手动覆盖安装 0.1.4 及以上版本，之后才能使用应用内更新。

从源码构建

项目代码采用 MIT 许可证。Windows 构建需要 PowerShell 7、Python、Rust MSVC 工具链、Visual Studio C++ 生成工具与 Windows SDK。

  • 在仓库根目录运行 pwsh -File .\build-windows.ps1 -Slim，安装包输出到 src-tauri/target/release/bundle/windows/。
  • macOS 使用 GitHub Actions 的「Windows and macOS packages」工作流，从同一份代码生成 EXE 与 arm64 DMG。
  • 发布前同步 tauri.conf.json、Cargo.toml 与 Cargo.lock 的版本号，再打对应标签（如 v0.1.7）。
  • 签名与自动更新的完整流程见仓库里的 UPDATES.md。

反馈与社区

使用中遇到问题，请到 GitHub Issues 提交。为了更快定位，请尽量带上：

  • 版本号（设置页「关于」里可见，当前为 0.1.7）和操作系统（如 Windows 11 x64 / macOS 14 Apple Silicon）。
  • 复现步骤、期望结果与实际结果。
  • 报错原文，并打码密码、App Secret、API Key 和内网地址。

功能建议、文档补充和 Pull Request 同样欢迎。项目由 Rui333333 维护，代码与发布包都在 GitHub 上公开。
