更新日志

记录每个公开版本实际交付的能力。需要安装包请到「历史版本」下载。

0.1.7 · 2026-11-27最新

  • 移除应用内录音、麦克风选择和相关权限
  • 「新建转录」直接进入音视频导入页，支持文件选择和拖放
  • 已有转录记录的回听、编辑和导出功能继续可用

0.1.6 · 2026-11-26

  • 转录片段逐段显示，队列支持取消、重试和重启恢复
  • 每个音视频文件可单独配置纠错词和热词
  • 转录时间戳限制在实际音轨范围内

0.1.5 · 2026-11-25

  • 新增 macOS 14+ Apple Silicon 支持，内置 CPU 转录引擎
  • 批量导出 SRT、TXT 或全部格式到一个 ZIP，支持搜索、分页与跨页勾选
  • 新版 Windows 安装器与卸载确认窗口，卸载时保留记录、设置和模型
  • 飞书发布支持删除已关联的云文档

0.1.4 · 2026-11-25

  • 首个支持应用内更新的版本，0.1.3 用户需下载安装包覆盖安装
  • 在「偏好设置 → 通用 → 检查更新」查看当前版本与可用更新
  • 改进确认转录页与「更多操作」菜单
